# The Shelf Website Design Guide

**Project:** The Shelf Website

**Version:** 1.0

**Last Updated:** 24 March 2026

---

# Vision

The Shelf is a digital agricultural market linkage and post-harvest management platform that connects farmers directly with buyers, helping reduce post-harvest losses, improve market access, and increase farmer incomes.

The website should communicate trust, innovation, sustainability, and real-world impact.

---

# Mission

Connecting Farmers to Markets.
Reducing Post-Harvest Losses.

---

# Primary Tagline

> Every Harvest Deserves a Market.

---

# Design Philosophy

The website should never feel like a generic e-commerce marketplace.

Instead, it should feel like:

- an agricultural innovation
- a development solution
- a technology platform
- an investment-ready startup

Every page should answer three questions:

1. What problem exists?
2. How does The Shelf solve it?
3. Why should people trust it?

Rounded outline icons.

# Animations

Subtle only.

Fade-in

Slide-up

Hover transitions

# Tone of Voice

Confident.

Clear.

Professional.

Human.

Hopeful.

Focus on solving real agricultural problems rather than promoting technology.

---

# Accessibility

Maintain sufficient colour contrast.

Use semantic HTML.

Provide alt text for all images.

Support keyboard navigation.

Responsive on all devices.
